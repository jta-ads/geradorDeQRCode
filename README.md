📱 Gerador de QR Code

Um simples e prático gerador de QR Codes, desenvolvido em HTML, CSS e JavaScript.
Permite que o usuário insira um texto ou link e obtenha o QR Code correspondente de forma rápida.

📖 Sobre o Projeto

Este projeto tem como objetivo demonstrar como gerar QR Codes diretamente no navegador utilizando JavaScript e bibliotecas específicas para geração da imagem do código.
Ele pode ser usado como base para aplicações maiores, integração em sistemas, ou apenas para estudo.

⚙️ Tecnologias Utilizadas

HTML5 → estrutura da aplicação

CSS3 → estilização da interface

JavaScript (Vanilla) → lógica de geração do QR Code

QRCode.js
 → biblioteca para geração do QR Code

🖥️ Como Usar
1. Clonar o repositório
git clone https://github.com/jta-ads/geradorDeQRCode.git

2. Acessar a pasta do projeto
cd geradorDeQRCode

3. Executar no navegador

Basta abrir o arquivo index.html no navegador de sua preferência.

🚀 Funcionalidades

Inserir texto ou URL no campo de entrada

Gerar automaticamente um QR Code correspondente

Exibir o QR Code na tela em tempo real

Possibilidade de salvar o QR Code gerado como imagem (dependendo da biblioteca usada)

📂 Estrutura de Pastas
geradorDeQRCode/
│── index.html       # Página principal
│── style.css        # Estilos da aplicação
│── script.js        # Lógica do QR Code
│── qrcode.min.js    # Biblioteca externa para geração
└── README.md        # Documentação do projeto

🛠️ Personalização

Você pode:

Alterar o tamanho do QR Code no script.js

Modificar as cores do QR Code (preto/branco ou outras combinações)

Adaptar a interface em style.css para seu estilo

📸 Exemplo de Uso

Digite um texto ou link no campo e clique em Gerar QR Code.
O código será exibido imediatamente na tela.
